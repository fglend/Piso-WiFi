SSH Access Whitelist

Restricts SSH (port 22) to listed MAC addresses. This does not change how the admin panel itself is reached — it is already only reachable from this device or through an SSH tunnel, so this whitelist protects that tunnel's entry point.

DoS Mitigation

SYN cookies plus a per-connection rate limit on the customer LAN.
{% set dos_on = app_settings.dos_protection_enabled in ('1', 'true', 'yes', 'on') %}
Rate limit is generous (20 new connections/sec, burst 40) so normal browsing is unaffected — this only bites during an actual flood.
